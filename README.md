# ❤️ Love Running

Love Running is a static website for a Dublin-based running club. It showcases the club's mission, running events, and signup page for new members.

## 🏃 Project overview

This project includes:

- 🏠 A landing page for the running club
- 🖼️ A gallery section with event visuals
- 📝 A registration form for new members
- 📱 Responsive styling for mobile and desktop screens

## ⚙️ Technologies used

- HTML5
- CSS3
- Font Awesome icons

## ▶️ Run locally

1. Open the project folder in your code editor.
2. Start a simple local web server if needed.
3. Open `index.html` in a browser.

Example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 📁 Files

- `index.html` — main landing page
- `gallery.html` — gallery page
- `signup.html` — registration form
- `assets/css/style.css` — site styling
